LLM Decision Lab

Compare four model answers through a small decision harness: project context, outcomes, rubrics, graders, deltas, adversarial review, and human approval.

Flow Guide

Project Context

60/40

Default scoring treats project instructions as 60% of the first-principles source and the current question as 40%.

Bulk Import

Local scoring is a rubric-based judge. For true model reasoning, use the judge prompt with your preferred LLM.

Judging Upgrades

Default-on upgrades reduce model-name bias, normalize the four answers before scoring, compare them twice, and stress-test the winner before synthesis.

Application Notes

  • Harness Engineering: wraps LLM answers with context intake, scoring controls, comparison traces, review loops, and a human gate.
  • Outcomes to Rubrics to Graders: defines what "done" means, converts it into scoring criteria, then uses the local grader and judge prompt to review outputs.
  • Multi-Agent Decision Pattern: four answers provide parallel perspectives; blind labels, claim extraction, two-pass judging, and adversarial review turn them into a better consolidated answer.

This browser app is a transparent showcase harness. It does not upload data or secretly read private files; you choose what to paste or load.
